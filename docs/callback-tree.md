# Callback Tree — Повний список екранів

> Повний перелік CallbackId для ієрархічної системи навігації Telegram бота.
> Дивись цей файл для розуміння структури UI та parent->child зв'язків.

## Нотатки

- **Геолокація обов'язкова** при створенні анкети "Я знайшов тварину"
- **Два типи оголошень**:
  - Стрічка = Lost & Found (знайдена тварина)
  - Адопція = передача тварини
- **Перетримка** — повторює логіку Адопції, але додає поле `тривалість`

### 180: FOSTER (Перетримка)
Parent: 100
Повторює логіку Адопії, але з полем `тривалість`

**Children:**
- 181: FOSTER_GIVE (Віддати тварину)
- 182: FOSTER_GET (Отримати тварину)
- 183: FOSTER_MY_RESPONSES (Мої відгуки)
- 184: FOSTER_MY_POSTS (Мої оголошення)

Після фінального підтвердження:
- Тварина → статус "На перетримці"
- Поле `тимчасовий власник` = user_id
- Після закінчення тривалості → автоматично повертається у стандартний статус
